# YSN Store

YSN Store helps Algerian social sellers create and manage a simple online shop.

## Stack

- Next.js App Router
- TypeScript
- Supabase
- Vercel

## Local setup

Install dependencies with `npm install`, then run `npm run dev`.

Set `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` in the environment when connecting Supabase features.
